## Before These Become Store Screenshots

- Create real completed drawings instead of the automated test strokes shown here.
- Capture the final release build in the device sizes requested by App Store Connect.
- Check each capture for permission dialogs, test artifacts, clipped content, and outdated UI.
- Keep these review images as engineering references; prepare the listing assets separately.

Interaction attachments and local `.xcresult` bundle paths are recorded in the [verification notes](../REVIEW.md). Signing, policy hosting, TestFlight, and submission remain separate steps in the [release checklist](../RELEASE.md).
